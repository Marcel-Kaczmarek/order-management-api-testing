# Defect Reports

Every report below is a **verified** finding against the pinned AUT (`andriiops/orderflow-api@259c7d0e`) in the local Docker environment. Each one was reproduced by automation, and the root cause was traced to upstream source where marked _verified_. None are illustrative. Templates for writing new reports are kept separately in [TEMPLATE.md](TEMPLATE.md).

**Environment (all reports):** Windows 11 Pro host, Docker Desktop 29.9.3 (engine shared with other workloads), `postgres:16-alpine`, AUT image built by `docker/aut.Dockerfile` (Node 22-alpine). Test runner: Playwright 1.65 on Node 24. Discovered 2026-11-24.
