## Top risks and recommended controls

1. **Inventory and checkout (R-03, R-08, R-10).** Replace the read-validate-decrement sequence with an atomic conditional decrement (`UPDATE … SET stock = stock - $q WHERE id = $id AND stock >= $q`) and check the affected row count. Aggregate quantities per product. Add `CHECK ("stock" >= 0)`. Restock on cancellation in the same statement batch as the status change. Map transaction errors to `503 Retry-After`, and add `Idempotency-Key` to `POST /orders`.
2. **State races (R-05).** Use optimistic conditional updates, `WHERE id = $id AND status = $from`. Treat 0 affected rows as `409 Conflict`.
3. **Deployability (R-11).** Fix the entrypoint path (BUG-007) and add a container smoke test to upstream CI.
4. **Abuse and input bounds (R-07, R-15).** Add `@nestjs/throttler` on `/auth/*`. Add `@Max` bounds for INT4 columns and route-ID validation. Map Prisma `P2002` errors to 409 and honour 4xx statuses from body-parser.
