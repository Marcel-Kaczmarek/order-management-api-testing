This document specifies the **high-priority test cases** in full. The complete, generated list of all 227 automated cases, with tags, requirement mapping and last result, is in [test-catalog.md](test-catalog.md). The requirement mapping is in the [RTM](requirements-traceability-matrix.md).

**Priority:** P1 = business-critical, run on every PR · P2 = important · P3 = edge or robustness.
**Automation status:** ✅ Automated · ⚠️ Automated, reproduces an open defect (`test.fail`) · 🧪 Automated, host-dependent (self-skips when its precondition isn't met).
